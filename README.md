# ポケGO 個体値ランクチェッカー

ポケモンGOの「評価」画面を画面収録した動画から個体値とポケモン名を読み取り、スーパー・ハイパー・マスターリーグで4096通り中何位かを、進化先も含めて表示するWebツールです。

動画はブラウザの中だけで処理され、外部には送信されません。

## 使い方
1. iPhoneの画面収録を開始
2. ポケモンを開いて「評価」→ バーが出たら1〜2秒待つ
3. 評価を開いたまま左右スワイプで次のポケモンへ
4. 録画を止めて、このページの「録画を選ぶ」から動画を選択（複数選択可）

表示は初期設定で「200位以内」に絞り込まれ、どのリーグ・進化先でも200位に入らない個体は非表示になります。

## 順位の計算
各リーグの上限CPに収まる最高レベル（上限Lv50/51切替）でのステータス積（攻撃×防御×HP）を、4096通りの個体値と比較しています。

## 開発
`src/` のファイルを編集して `python src/build.py` を実行すると `index.html` が作られます。

## データ
- 種族値: [PvPoke](https://github.com/pvpoke/pvpoke) のゲームマスター
- 日本語名: [PokeAPI](https://github.com/PokeAPI/pokeapi)
